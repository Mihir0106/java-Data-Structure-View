Java Collections Hierarchy

Blue = Interface (Rules) | Red = Class (Implementation)

1. The Collection Family

Iterable<T> Interface
iterator() → allows foreach loop
⬇
Collection<T> Interface
add(E e) remove(Object o) contains(Object o) size() isEmpty() clear() toArray()
⬇
List<T> Interface
get(int index) set(int index, E e) add(int index, E e) indexOf(Object o)
⬇
ArrayList
Fast access, slow insert.
LinkedList
Fast insert, slow access.
Queue<T> Interface
offer(E e) // safe add poll() // remove head peek() // view head
⬇
PriorityQueue
Sorted by priority.
LinkedList
Standard FIFO Queue.
Set<T> Interface
No new methods. Enforces uniqueness.
⬇
HashSet
Unordered, Fast (O1).
TreeSet
Sorted, Slower (LogN).

2. The Map Family

(Maps are NOT Collections. They stand alone.)

Map<K, V> Interface
put(K key, V value) get(Object key) getOrDefault(key, default) containsKey(Object key) containsValue(Object val) remove(Object key) size()
⬇
Iterating Views
keySet() → Set<K> values() → Collection<V> entrySet() → Set<Entry>
⬇
HashMap
Fastest. Unordered. Allows 1 null key.
LinkedHashMap
Remembers insertion order.
TreeMap
Sorted by Key (Natural or Custom).
Map.Entry<K,V> Helper
getKey() getValue() setValue(V v)
