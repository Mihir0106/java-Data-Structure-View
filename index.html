3. Method Reference & Complexity Guide

Detailed breakdown with Time & Space Complexity.

List Methods (ArrayList vs LinkedList)

Space: O(n) for both.
Key Diff: ArrayList = Fast Read. LinkedList = Fast Add/Remove at ends.

add(E element) AL: O(1) | LL: O(1)
Appends element to the end. (ArrayList is amortized O(1)).
list.add("Apple");
add(int index, E element) AL: O(n) | LL: O(n)
AL: Shifts elements right (Slow).
LL: Traverse to node (Slow), then insert (Fast).
list.add(0, "Pear");
get(int index) AL: O(1) | LL: O(n)
AL: Instant access.
LL: Must traverse from head/tail.
list.get(1);
remove(int index) AL: O(n) | LL: O(n)
Removing requires shifting (AL) or seeking (LL).
list.remove(0);

PriorityQueue Methods (Heap)

Space: O(n). Based on Binary Heap.

offer(E e) Time: O(log n)
Adds element. Needs "Heapify Up" to fix order.
pq.offer(10);
poll() Time: O(log n)
Removes head. Needs "Heapify Down" to fix order.
pq.poll();
peek() Time: O(1)
Instantly view the top element (root of Heap).
pq.peek();

HashMap Methods

Space: O(n).
Note: Complexity is "Average Case". Worst case O(n) if hash collisions occur (rare).

put(K key, V value) Time: O(1)
Computes Hash -> Finds Bucket -> Inserts.
map.put("A", 1);
get(Object key) Time: O(1)
Computes Hash -> Finds Bucket -> Returns Value.
map.get("A");
containsKey(Key) Time: O(1)
checks if hash bucket exists and contains key.
map.containsKey("A");
remove(Object key) Time: O(1)
Unlinks the node from the bucket.
map.remove("A");

TreeMap Methods (Red-Black Tree)

Space: O(n).
Note: Slower than HashMap, but keeps keys sorted.

put(K key, V value) Time: O(log n)
Tree traversal to find correct spot.
treeMap.put(5, "A");
get(Object key) Time: O(log n)
Binary Search traversal.
treeMap.get(5);
firstKey() / lastKey() Time: O(log n)
Find smallest or largest key.
treeMap.firstKey();

4. Generics, Primitives & Arrays Rules

Why PriorityQueue<int[]> works but Map<int,int> doesn't.

The Golden Rule of Generics

Generic types (<T>) MUST be Reference Types (Objects). They cannot be Primitives.
  • ❌ List<int> (Primitive)
  • ✅ List<Integer> (Wrapper Object)
  • ✅ List<String> (Object)

The Array Exception

In Java, Arrays are Objects. Even an array of primitives (int[]) is an Object on the Heap.
  • ✅ List<int[]> (List of Integer Arrays)
  • ✅ PriorityQueue<int[]> (Queue of Arrays)

Valid vs Invalid Examples

Code Valid? Reason
PriorityQueue<int> ❌ No int is a primitive.
PriorityQueue<Integer> ✅ Yes Integer is a Wrapper Object.
PriorityQueue<int[]> ✅ Yes int[] (Array) is an Object.
Map<int, int> ❌ No Primitives not allowed in <K,V>.

Helper methods you use every day.

7. Primitives vs. Objects & Arrays

Why int.toString() fails but Integer.toString() works.

Primitives vs. Wrapper Objects

Primitives (`int`, `char`, `double`) are raw data. They have NO methods.
  • ❌ int x = 5; x.toString(); // Compile Error
  • ✅ Integer x = 5; x.toString(); // Valid
  • ✅ String.valueOf(5); // Static helper required

Primitive Array vs. Object Array

They are totally different types. No Autoboxing between arrays.
char[] (Primitive)
Contiguous memory. Fast. Returned by String.toCharArray().
Character[] (Object)
Array of references. Heavy. No built-in conversion from char[].

How to Convert? (Primitive Array ↔ Object Array)

Goal Code Strategy
String → char[]
char[] arr = str.toCharArray();
String → Character[] ❌ No direct method. Must loop or use Streams:
Character[] ch = str.chars()
  .mapToObj(c -> (char)c)
  .toArray(Character[]::new);
int[] → Integer[] ❌ No Autoboxing. Must loop or use Streams:
Integer[] arr = Arrays.stream(toIntArray)
  .boxed().toArray(Integer[]::new);

8. Wrapper & String Utilities Reference

Essential methods for Integer, Character, and String.

Integer / Double Methods

Integer.parseInt(String s)
Parses string to primitive int. Throws exception if invalid.
int x = Integer.parseInt("123");
Integer.valueOf(String s)
Parses string to Integer object (Cached for small numbers).
Integer x = Integer.valueOf("123");
Integer.toString(int i)
Converts number to String.
String s = Integer.toString(123);
Integer.compare(int a, int b)
Returns -1, 0, or 1. Useful for sorting logic.
Integer.compare(5, 10); // -1

Character Methods

Character.isDigit(char c)
Checks if character is 0-9.
boolean b = Character.isDigit('5');
Character.isLetter(char c)
Checks if character is a letter (a-z, A-Z).
boolean b = Character.isLetter('a');
Character.toLowerCase(char c)
Converts to lowercase.
char c = Character.toLowerCase('A');
Character.getNumericValue(char c)
Returns int value of digit char.
int i = Character.getNumericValue('5'); // 5

Essential String Methods

length()
Returns char count.
charAt(int index)
Returns char at index.
substring(start, end)
Returns slice. End index is exclusive.
"hello".substring(1, 3); // "el"
indexOf(String s)
Returns first index of sub-string or -1.
contains(CharSequence s)
Returns true if string contains sequence.
trim() / strip()
Removes whitespace from ends.
split(String regex)
Splits string into String array.
"a,b".split(","); // ["a", "b"]
toCharArray()
Converts to primitive char[].
equals(Object o)
Compares values. NEVER use == for Strings!
startsWith(prefix)
Checks if string starts with prefix.
